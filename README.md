# Probashi Store — Business management

A responsive, browser based business dashboard using the supplied Probashi Store logo and its navy, gold and warm ivory palette.

## Open it

Open `index.html` in a modern browser. No build step or dependency installation is required.

## Demo sign in

- Email: `admin@probashi.store`
- Password: `probashi123`

The dashboard includes overview metrics, order and product lists, customer records, expenses, reports, settings, search and status filters, CSV order export, and forms for adding orders, products and expenses. Added records and the sign in session are stored in this browser's local storage.

## Data and access

This is a front end demo. The displayed starting figures and customer/order records are sample data; they are not connected to a real store. The demo sign in is a browser side gate, not production authentication. A real deployment needs a server, database, permission checks and securely managed authentication before using actual business or customer data.
